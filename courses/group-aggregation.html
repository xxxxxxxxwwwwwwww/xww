编写一个程序，加载销售数据并进行基础的分组聚合分析。

输入：

销售数据集，包含日期、地区、产品类别、销售额等字段

输出：

按地区分组的总销售额统计

要求：

  • 创建示例销售数据
  • 使用groupby按地区分组
  • 计算各地区的总销售额

答案解析

解题思路

1. 使用Pandas创建DataFrame

2. 使用groupby按地区列分组

3. 使用sum()计算总销售额

代码示例

import pandas as pd
import numpy as np

# 创建示例销售数据
data = {
    'date': ['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04', '2024-01-05'],
    'region': ['华东', '华北', '华南', '华东', '华北'],
    'category': ['电子产品', '服装', '食品', '电子产品', '服装'],
    'sales': [1500, 800, 500, 2000, 1200]
}
df = pd.DataFrame(data)

# 按地区分组并计算总销售额
region_sales = df.groupby('region')['sales'].sum()

print("各地区销售总额：")
print(region_sales)

模块1：分组聚合基础（8学时）

分组聚合概述

分组聚合是数据分析中最常用的操作之一，通过将数据按某些特征分组，然后对每组应用聚合函数（如求和、均值、计数等）来提取有价值的信息。

🎯 核心概念

分组（Split）→ 应用（Apply）→ 合并（Combine）

📊 应用场景

销售统计、用户行为分析、财务报表、科学实验分析

import pandas as pd

# 基础分组示例
df = pd.DataFrame({
    'category': ['A', 'B', 'A', 'B'],
    'value': [10, 20, 30, 40]
})

# 按类别分组并计算均值
grouped = df.groupby('category')['value'].mean()
print(grouped)

常用聚合函数

Pandas提供了丰富的聚合函数，可以对分组后的数据进行各种统计计算。

📊 数学统计

sum(), mean(), median(), std(), var()

🔢 计数与极值

count(), size(), min(), max()

🎯 分位数

quantile(), describe()

模块2：高级聚合与透视表（8学时）

多列分组

可以同时按多个列进行分组，创建层次化的分组结构，进行更精细的数据分析。

🔍 多维度分析

按地区+产品类别、按时间+部门等多重维度分组

📋 多级索引

groupby返回的结果可能是MultiIndex，便于层次化数据访问

# 多列分组示例
grouped = df.groupby(['region', 'category'])['sales'].agg(['sum', 'mean'])
print(grouped)

透视表

pivot_table是Pandas中强大的数据重塑工具，可以快速创建交叉表和汇总报表。

# 透视表示例
pivot = pd.pivot_table(
    df, 
    values='sales',
    index='region',
    columns='category',
    aggfunc='sum',
    fill_value=0
)
print(pivot)

聚合结果可视化

将分组聚合的结果通过图表直观展示，帮助发现数据中的规律和趋势。

📊 柱状图/条形图

用于比较不同类别的数值大小

📈 折线图

用于展示时间序列趋势

import matplotlib.pyplot as plt

# 可视化分组结果
region_sales.plot(kind='bar', figsize=(10, 6))
plt.title('各地区销售额对比')

plt.ylabel('销售额')
plt.show()
