编写一个程序，加载销售数据并进行基础分组分析。

包含销售记录的DataFrame

按产品类别分组的销售统计

要求：

  • 加载示例数据
  • 按产品类别分组
  • 计算销售额的总和和平均值

答案解析

解题思路

1. 使用pandas创建或加载销售数据

2. 使用groupby()按产品类别分组

3. 使用agg()或聚合函数计算统计指标

代码示例

import pandas as pd
import numpy as np

# 创建示例销售数据
data = {
    '产品类别': ['电子产品', '服装', '食品', '电子产品', '服装', '食品', '电子产品', '服装'],
    '销售额': [1200, 850, 320, 2100, 560, 480, 1800, 720],
    '销量': [2, 3, 8, 3, 2, 12, 2, 4],
    '地区': ['北京', '上海', '广州', '深圳', '北京', '上海', '广州', '深圳']
}
df = pd.DataFrame(data)

# 按产品类别分组并计算统计指标
result = df.groupby('产品类别').agg({
    '销售额': ['sum', 'mean', 'count'],
    '销量': ['sum', 'mean']
}).round(2)

print("按产品类别分组的销售统计：")
print(result)

模块1：分组聚合基础（8学时）

groupby基础

分组聚合是数据分析中最常用的操作之一。groupby的核心思想是"split-apply-combine"：将数据分组、对每组应用函数、再将结果合并。

🎯 核心步骤

split（分组）→ apply（应用）→ combine（合并）

📊 常用场景

按时间分组、按类别分组、按地区分组等

import pandas as pd

# 基础分组
df.groupby('类别')
df.groupby(['类别', '地区'])  # 多列分组

# 分组后选择列
df.groupby('类别')['销售额']
df.groupby('类别')[['销售额', '销量']]

聚合函数

聚合函数用于对分组后的数据进行统计计算，如求和、均值、最大值等。

📊 常用聚合函数

sum()、mean()、count()、std()、var()、min()、max()、median()

🔗 agg()方法

可以同时应用多个聚合函数

# 单个聚合函数
df.groupby('类别')['销售额'].sum()

# 多个聚合函数
df.groupby('类别').agg({
    '销售额': ['sum', 'mean', 'max'],
    '销量': ['sum', 'count']
})

# 使用命名聚合
df.groupby('类别').agg(
    总销售额=('销售额', 'sum'),
    平均销量=('销量', 'mean')
)

模块2：高级聚合分析（8学时）

透视表与交叉表

pivot_table()和crosstab()是处理复杂分组聚合的强大工具，特别适合多维度分析。

📊 pivot_table

用于创建数据透视表，支持多索引、多值和自定义聚合

📈 crosstab

用于计算交叉表，特别适合频数统计

# 透视表
pd.pivot_table(df, 
               values='销售额', 
               index='产品类别', 
               columns='地区', 
               aggfunc='sum',
               margins=True)

# 交叉表
pd.crosstab(df['产品类别'], 
            df['地区'],
            values=df['销售额'],
            aggfunc='sum',
            normalize=True)

窗口函数与自定义聚合

窗口函数允许在不分组的情况下进行滑动窗口计算，自定义聚合函数满足特殊需求。

🔍 窗口函数

rolling()、expanding()、transform()、shift()等

✏️ 自定义聚合

使用apply()或transform()应用自定义函数

# 滚动窗口
df['7天移动平均'] = df.groupby('产品类别')['销售额'].rolling(7).mean().values

# 自定义聚合函数
def iqr(x):
    return x.quantile(0.75) - x.quantile(0.25)

df.groupby('类别')['销售额'].agg(['mean', iqr])

# transform使用
df['组内占比'] = df['销售额'] / df.groupby('类别')['销售额'].transform('sum')
