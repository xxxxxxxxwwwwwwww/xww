使用Pandas的groupby功能对数据进行分组和聚合操作。

要求：

  • 使用groupby按产品类别分组
  • 计算每个类别的销售总额
  • 计算每个类别的订单数量

答案解析

解题思路

1. 使用groupby()按类别分组

2. 使用agg()进行多指标聚合

3. 重置索引得到DataFrame

代码示例

import pandas as pd

data = {
    'category': ['电子产品', '服装', '电子产品', '食品', '服装'],
    'product': ['手机', 'T恤', '电脑', '面包', '裤子'],
    'price': [3000, 200, 5000, 15, 300],
    'quantity': [1, 2, 1, 5, 1]
}
df = pd.DataFrame(data)

result = df.groupby('category').agg({
    'price': 'sum',
    'quantity': 'sum',
    'product': 'count'
}).rename(columns={'product': 'order_count'})

print("按类别分组统计:")
print(result)

模块1：分组聚合基础

groupby概述

groupby是Pandas中用于数据分组和聚合的核心功能，类似于SQL中的GROUP BY语句。它允许你将数据按照一个或多个列进行分组，然后对每个组应用聚合函数。

df.groupby('category')
  .agg({'sales': 'sum'})

常用聚合函数

📊 sum()

计算总和

📈 mean()

计算平均值

📉 count()

计算数量

模块2：高级聚合分析

agg()自定义聚合

agg()函数允许你对不同的列应用不同的聚合函数，实现更灵活的统计分析。

df.groupby('category').agg({
    'sales': ['sum', 'mean'],
    'quantity': 'max'
})

transform()

transform()函数可以对分组后的数据进行转换，保持原数据的结构。

df['category_mean'] = df.groupby(
    'category')['price'].transform('mean')
