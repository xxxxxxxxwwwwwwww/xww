问题1：转化率计算

00:00
简单

计算A/B测试中各组的转化率。

输入：A组和B组的访问人数和转化人数

输出：各组的转化率和相对提升

要求：

  • 计算A组转化率
  • 计算B组转化率
  • 计算相对提升
  • 输出对比结果

答案解析

解题思路

1. 计算转化率 = 转化人数 / 访问人数

2. 计算相对提升 = (B转化率 - A转化率) / A转化率

3. 格式化输出结果

代码示例

import pandas as pd

data = {
    'group': ['A', 'B'],
    'visitors': [10000, 10000],
    'conversions': [320, 380]
}
df = pd.DataFrame(data)

df['conversion_rate'] = df['conversions'] / df['visitors'] * 100

control_rate = df[df['group'] == 'A']['conversion_rate'].values[0]
treatment_rate = df[df['group'] == 'B']['conversion_rate'].values[0]
lift = (treatment_rate - control_rate) / control_rate * 100

print("A/B测试结果:")
print(df)
print(f"\\n相对提升: {lift:.2f}%")

模块1：A/B测试基础

A/B测试概述

A/B测试是一种对照实验方法，通过将用户随机分组，对比不同方案的效果差异，用于数据驱动的决策。

A组（对照组）: 原方案
B组（实验组）: 新方案

转化率A = 320/10000 = 3.2%
转化率B = 380/10000 = 3.8%
提升 = (3.8-3.2)/3.2 = 18.75%

核心指标

📊 转化率

转化人数 / 访问人数

📈 相对提升

(B-A)/A × 100%

🔢 样本量

影响结果的统计功效

模块2：高级A/B测试

统计显著性

统计显著性用于判断观察到的差异是真实存在的还是随机波动产生的。通常要求p值小于0.05。

p值 < 0.05: 结果显著
p值 < 0.01: 结果高度显著

95%置信区间不包含0
= 结果具有统计显著性

卡方检验

卡方检验用于判断两组之间的差异是否具有统计显著性。

from scipy.stats import chi2_contingency

table = [[320, 9680], [380, 9620]]
chi2, p, dof, expected = chi2_contingency(table)

print(f"卡方值: {chi2:.2f}")
print(f"p值: {p:.4f}")
print(f"显著性: {'是' if p < 0.05 else '否'}")
