import pandas as pd
from collections import Counter

# 创建示例购物篮数据
data = {
    'TransactionID': [1, 1, 2, 2, 2, 3, 3, 4, 4, 4, 5],
    'Item': ['牛奶', '面包', '面包', '鸡蛋', '牛奶', '牛奶', '鸡蛋', '面包', '鸡蛋', '牛奶', '面包']
}
df = pd.DataFrame(data)

print("数据预览：")
print(df)
print("\n" + "="*50)

# 统计基本信息
total_transactions = df['TransactionID'].nunique()
total_items = df['Item'].nunique()
print(f"总交易数：{total_transactions}")
print(f"商品种类数：{total_items}")

# 统计商品频率
item_counts = df['Item'].value_counts()
print("\n商品销售排名：")
print(item_counts)

print("\n最热门商品：")
print(f"{item_counts.index[0]}，销售{item_counts.iloc[0]}次")

模块1：购物篮分析基础（45分钟）

什么是购物篮分析

购物篮分析是一种数据挖掘技术，用于发现顾客购买的商品之间的关联关系。通过分析交易数据，找出哪些商品经常被一起购买。

🛒 经典案例

啤酒与尿布：美国超市发现周五下午买尿布的顾客经常也买啤酒，将它们放在一起后销量大增。

🎯 应用场景

商品陈列优化、交叉销售推荐、促销活动设计、库存管理等。

关联规则基本概念

关联规则是形如 X → Y 的表达式，表示购买了商品X的顾客也很可能购买商品Y。

📊 支持度（Support）

同时包含X和Y的交易占总交易的比例。

Support = P(X∩Y)
🔗 置信度（Confidence）

购买了X的顾客中也购买Y的比例。

Confidence = P(Y|X)
⚡ 提升度（Lift）

购买X对购买Y的提升程度，大于1表示正相关。

Lift = P(Y|X) / P(Y)

模块2：Apriori算法（50分钟）

Apriori原理

Apriori算法利用一个重要性质：如果一个项集是频繁的，那么它的所有子集也都是频繁的；反之，如果一个项集是不频繁的，那么它的所有超集也都是不频繁的。

🔍 核心思想

通过逐层搜索的方式，先找出所有频繁1项集，再用它们找频繁2项集，以此类推。

⚡ 优化技巧

利用先验性质剪枝，避免搜索不可能频繁的项集，大幅减少计算量。

算法步骤

Apriori算法分为两个主要阶段：频繁项集挖掘和关联规则生成。

1️⃣ 频繁项集挖掘
  • 设置最小支持度阈值
  • 找出所有满足支持度的项集
  • 从k项集生成k+1项集候选
  • 剪枝、测试，直到无法生成
2️⃣ 关联规则生成
  • 从每个频繁项集生成所有可能规则
  • 计算置信度和提升度
  • 筛选满足阈值的规则

模块3：结果可视化与应用（45分钟）

可视化方法

通过可视化技术，将复杂的关联规则转化为直观的图表，帮助理解和决策。

📊 散点图

用支持度和置信度作为坐标轴，每个点代表一条规则。

🕸️ 网络图

节点代表商品，边代表关联关系，边的粗细代表强度。

📈 热力图

展示商品之间的共现频率矩阵。

业务应用

购物篮分析的结果可以直接应用于业务决策，提升销售和用户体验。

🏪 商品陈列优化

将强关联的商品放在相近位置，促进连带购买。

🎁 促销活动设计

基于关联规则设计捆绑销售和组合优惠。

💡 推荐系统

用户浏览或购买商品A时，推荐关联商品B。
