答案解析

解题思路

1. 使用Python字典统计每个商品出现的频率

2. 使用collections.Counter进行高效统计

3. 排序后提取Top 10商品

代码示例

from collections import Counter, defaultdict

# 示例购物篮数据
transactions = [
    ['面包', '牛奶', '鸡蛋'],
    ['牛奶', '鸡蛋', '啤酒'],
    ['面包', '牛奶', '啤酒', '薯片'],
    ['面包', '薯片'],
    ['牛奶', '鸡蛋', '面包'],
    ['啤酒', '薯片'],
    ['面包', '牛奶', '鸡蛋', '薯片'],
    ['牛奶', '鸡蛋'],
    ['面包', '啤酒'],
    ['鸡蛋', '薯片']
]

print("=== 购物篮数据探索 ===")
print(f"总交易次数: {len(transactions)}")

# 统计所有商品
all_items = [item for transaction in transactions for item in transaction]
item_counts = Counter(all_items)

print(f"商品总种类数: {len(item_counts)}")
print("\n商品频率统计:")
for item, count in item_counts.items():
    print(f"  {item}: {count}次 ({count/len(transactions)*100:.1f}%)")

print("\nTop 5 最频繁商品:")
for item, count in item_counts.most_common(5):
    print(f"  {item}: {count}次")

模块1：购物篮分析基础

什么是购物篮分析

购物篮分析（Market Basket Analysis）是数据挖掘技术在零售业的典型应用，通过分析顾客购物篮中的商品组合，发现商品之间的关联关系，从而制定营销策略。

🎯 核心目标

找出哪些商品经常被一起购买，发现商品间的关联规则。

📊 典型应用

商品摆放优化、交叉销售推荐、促销策略制定。

# 购物篮分析示例数据
# 每条记录代表一次交易
transactions = [
    ['面包', '牛奶', '鸡蛋'],
    ['牛奶', '鸡蛋', '啤酒'],
    ['面包', '牛奶', '啤酒', '薯片'],
    # ... 更多交易记录
]

# 经典案例："啤酒与尿布"
# 发现：购买尿布的顾客常购买啤酒
# 原因：年轻父亲周末购物，顺便买啤酒

关联规则基本概念

关联规则表示为 A → B，表示购买了A的顾客很可能也会购买B。需要通过三个指标来评估规则的质量。

📌 支持度（Support）

Support(A→B) = 同时包含A和B的交易数 / 总交易数

表示商品组合的流行程度

📌 置信度（Confidence）

Confidence(A→B) = 同时包含A和B的交易数 / 包含A的交易数

表示购买A时购买B的条件概率

📌 提升度（Lift）

Lift(A→B) = Confidence(A→B) / Support(B)

Lift>1表示A对B有正向促进作用

模块2：Apriori算法

Apriori原理

Apriori算法是最经典的频繁项集挖掘算法，利用先验知识（Apriori原理）来减少搜索空间。

🔑 核心原理

如果一个项集是频繁的，那么它的所有非空子集也必须是频繁的。

💡 逆否命题

如果一个项集是非频繁的，那么它的所有超集也一定是非频繁的。

# Apriori原理示例
# 假设最小支持度为 2/5 = 40%

transactions = [
    ['A', 'B', 'C'],
    ['A', 'B'],
    ['A', 'C'],
    ['A', 'B', 'D'],
    ['B', 'C']
]

# 如果 {'A', 'B', 'C'} 是频繁的
# 那么其子集 {'A','B'}, {'A','C'}, {'B','C'} 也必须是频繁的

# 如果 {'D'} 不频繁（支持度1/5=20%）
# 那么包含D的所有超集都不频繁

算法步骤

Apriori算法分为两个主要阶段：找出所有频繁项集，然后从频繁项集中生成强关联规则。

1️⃣ 找出频繁项集

从1-项集开始，逐步迭代，利用Apriori原理剪枝。

2️⃣ 生成关联规则

从每个频繁项集生成所有可能的规则，筛选满足最小置信度的规则。

3️⃣ 评估规则质量

使用提升度等指标进一步筛选有意义的规则。

模块3：结果可视化与应用

可视化方法

购物篮分析结果的可视化有助于直观理解商品间的关系，常见的可视化方式包括：

📊 散点图

横轴支持度，纵轴置信度，点大小表示提升度。

🕸️ 网络图

节点表示商品，边表示关联规则，边粗细表示强度。

📈 柱状图

展示频繁商品或强规则的排名。

🔥 热力图

展示商品两两共同出现的频率矩阵。

业务应用

购物篮分析的结果可以应用于零售业的多个方面，帮助提升销售和客户体验。

🛒 商品陈列优化

将强关联商品放在一起，增加交叉销售机会。

🎁 捆绑销售策略

将频繁一起购买的商品组合成套餐，优惠销售。

💡 个性化推荐

根据顾客当前购物车商品，推荐关联商品。

📢 促销活动设计

针对关联商品设计促销，A打折时B不打折。

📦 库存管理优化

关联商品的库存协调管理。
