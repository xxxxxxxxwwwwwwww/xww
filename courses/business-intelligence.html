问题1：缺失值处理

00:00
简单

编写一个程序，使用Pandas处理DataFrame中的缺失值。

输入：

一个包含缺失值的DataFrame

输出：

处理后的DataFrame，其中缺失值已被适当处理

要求：

  • 识别并统计缺失值
  • 使用合适的方法填充缺失值（如均值、中位数或众数）
  • 返回处理后的DataFrame

答案解析

解题思路

1. 使用Pandas的isnull()和sum()方法识别并统计缺失值

2. 根据数据类型选择合适的填充方法：数值型数据使用均值或中位数，分类型数据使用众数

3. 使用fillna()方法填充缺失值

代码示例

import pandas as pd
import numpy as np

# 创建示例数据
data = {
    'A': [1, 2, np.nan, 4, 5],
    'B': [np.nan, 2, 3, 4, np.nan],
    'C': ['x', 'y', 'z', np.nan, 'x']
}
df = pd.DataFrame(data)

# 识别缺失值
print("缺失值统计:")
print(df.isnull().sum())

# 处理缺失值
df['A'] = df['A'].fillna(df['A'].mean())
df['B'] = df['B'].fillna(df['B'].median())
df['C'] = df['C'].fillna(df['C'].mode()[0])

print("\n处理后的数据:")
print(df)

模块2：数据仓库设计（12学时）

数据仓库概念与特点

数据仓库（Data Warehouse）是一个面向主题的、集成的、相对稳定的、反映历史变化的数据集合，用于支持管理决策。

# 数据仓库四大特征 (ACID)

1. 面向主题 (Subject-Oriented)
   - 围绕特定业务主题组织数据
   - 如：销售、客户、产品、财务

2. 集成性 (Integrated)
   - 统一数据格式和编码标准
   - 消除数据不一致性

3. 非易失性 (Non-Volatile)
   - 数据一旦加载，不进行更新
   - 支持历史数据分析

4. 时变性 (Time-Variant)
   - 包含历史数据
   - 支持时间序列分析

# 数据仓库 vs 操作型数据库

└──────────────┴─────────────┴─────────────┘

模块3：OLAP分析（12学时）

OLAP基本概念

OLAP（Online Analytical Processing）联机分析处理，是一种软件技术，它允许用户从多个视角快速、交互式地分析数据。

OLAP特点
  • 多维数据分析
  • 快速响应查询
  • 支持复杂计算
  • 灵活的报表生成
OLAP类型
  • MOLAP：多维OLAP，基于多维数组存储
  • ROLAP：关系OLAP，基于关系数据库
  • HOLAP：混合OLAP，结合两者优势

# 5. 聚合 (Aggregate)
# 计算汇总统计

    'sales': ['sum', 'mean', 'count'],

预测分析

预测分析利用历史数据和统计模型来预测未来趋势，支持前瞻性决策。

# 时间序列预测示例
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA
from sklearn.linear_model import LinearRegression
import numpy as np

# 销售数据预测
sales_data = pd.DataFrame({
    'date': pd.date_range('2023-01', periods=12, freq='M'),
    'sales': [100, 120, 150, 130, 160, 180, 
              200, 190, 210, 230, 250, 280]
})

# ARIMA模型
model = ARIMA(sales_data['sales'], order=(1, 1, 1))
fitted = model.fit()
forecast = fitted.forecast(steps=3)
print("未来3个月销售预测:", forecast)

# 线性回归预测
X = np.arange(len(sales_data)).reshape(-1, 1)
y = sales_data['sales'].values
lr = LinearRegression()
lr.fit(X, y)
future_X = np.arange(len(sales_data), len(sales_data) + 3).reshape(-1, 1)
future_sales = lr.predict(future_X)
print("线性趋势预测:", future_sales)

# 预测评估指标
from sklearn.metrics import mean_absolute_error, mean_squared_error
mae = mean_absolute_error(y_true, y_pred)
rmse = np.sqrt(mean_squared_error(y_true, y_pred))

优化模型

优化模型帮助企业在约束条件下找到最优解决方案，实现资源的最优配置。

# 线性规划示例：生产计划优化
from scipy.optimize import linprog

# 问题：最大化利润
# 产品A利润100元，产品B利润150元
# 约束：原材料、工时、设备

# 目标函数系数（最小化负值 = 最大化）
c = [-100, -150]

# 约束条件系数矩阵
A_ub = [
    [2, 3],    # 原材料约束
    [4, 2],    # 工时约束
    [1, 1]     # 设备约束
]

# 约束条件右端值
b_ub = [100, 120, 50]

# 变量非负约束
x_bounds = [(0, None), (0, None)]

# 求解
result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=x_bounds)

print(f"最优产量：产品A={result.x[0]:.2f}, 产品B={result.x[1]:.2f}")
print(f"最大利润：{-result.fun:.2f}元")

# 库存优化模型
def eoq(demand, order_cost, holding_cost):
    """经济订货量模型"""
    import math
    return math.sqrt(2 * demand * order_cost / holding_cost)

# 年需求10000件，订货成本50元，持有成本2元/件/年
optimal_order = eoq(10000, 50, 2)
print(f"最优订货量：{optimal_order:.0f}件")
