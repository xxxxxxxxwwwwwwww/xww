代码示例

import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
import numpy as np

data = {
    'customer_id': range(1, 11),
    'age': [25, 45, 35, 28, 52, 38, 42, 30, 55, 33],
    'income': [50000, 120000, 75000, 45000, 150000, 80000, 95000, 55000, 180000, 65000],
    'spending': [3000, 15000, 8000, 2500, 20000, 9000, 11000, 4000, 25000, 7000]
}
df = pd.DataFrame(data)

features = ['age', 'income', 'spending']
X = df[features]

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
df['cluster'] = kmeans.fit_predict(X_scaled)

print("聚类中心:")
print(pd.DataFrame(scaler.inverse_transform(kmeans.cluster_centers_), columns=features))

print("\n各簇客户数量:")
print(df['cluster'].value_counts().sort_index())

模块1：聚类分析基础

聚类分析概述

聚类分析是一种无监督学习方法，用于将相似的对象分组到同一个簇中。K-Means是最常用的聚类算法之一。

from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3)
labels = kmeans.fit_predict(X)

K-Means算法步骤

📍 初始化

随机选择K个点作为初始质心

📊 分配

将每个点分配到最近的质心

🔄 更新

重新计算每个簇的质心

模块2：高级聚类应用

肘部法则

肘部法则用于确定最佳的聚类数量K，通过绘制K值与SSE的关系曲线，找到"肘部"点。

inertias = []
for k in range(1, 10):
    kmeans = KMeans(n_clusters=k)
    kmeans.fit(X)
    inertias.append(kmeans.inertia_)

plt.plot(range(1, 10), inertias, 'bx-')

轮廓系数

轮廓系数衡量聚类质量，取值范围[-1, 1]，越接近1表示聚类效果越好。

from sklearn.metrics import silhouette_score

score = silhouette_score(X, labels)
print(f"轮廓系数: {score:.3f}")
